# Fresh Brew Cafe — Landing Page

A responsive landing page for a fictional cafe, built to practice HTML, CSS, and layout design (Flexbox/Grid).

## Features
- Hero section with call-to-action button
- Menu section with responsive card grid
- Styled footer with contact details
- Fully responsive design

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid)
